# Agents and runs (Paperclip-style)
@from paperclip (seen running), control-center
> 1 An agent is a named employee. The left sub-navigation groups its settings: Agent (overview, instructions, skills), Runtime (harness, secrets, tools), Governance (permissions and trust, revisions), Audit (activity, runs, costs, budgets).
> 2 The runs list shows the trigger, tokens and the first line of each result. A run that did nothing is labelled, so wasted wake-ups are obvious (F134).
> 3 Skills are enabled per agent and the change applies on the next run. A "Test your agent" check proves the runtime responds.

        stat "Tokens today" "212k" hint="avg 35k per run"
        stat "Trigger mix" "3 / 2 / 1" hint="assignment / manual / wake"
      table "Run" "Trigger" "Tokens" "Result" n=2
