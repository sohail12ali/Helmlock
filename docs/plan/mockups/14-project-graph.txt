> 1 The graph is built from small node notes in the project. A node has a type, a one-line summary and typed outgoing edges. The page filters by edge type and depth.
> 2 A node page shows its edges and the backlinks, which are computed, never stored by hand. A lint panel lists broken links, orphans and missing summaries.
> Obsidian shows the same notes natively; this view adds typed edges and a project filter.
